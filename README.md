# VarMasters
A selection of various tools built during my masters degree alongside of projects to speed up my workflow alongside of others


-------------------------------
# Aprox_BallBounce_Simulation_02

A script done for a ball bounce assignment to show pure basic physic parameters and visualize concepts in Maya for things like free fall, air density, weight, spin, but especially different material lookups for restitution and friction

--------------------------------
# Golden_Ratio

a tool designed to be a digital measuring tool to resemble a golden ratio 3-point measurement, important for designs of cartoon objects and concept modelling/blocking

-------------------------------
# combine_objects

In the default Maya ui, Maya creates a polyUnite note that leaves transform1, transform2, etc in the outliner, and deletes construction history, this will allow for automatically flattened process with a safety clearing.

------------------------------
# curve_to_loc

creates a chain of locators based upon curve, this was built for a rigging guide and testing a skeleton generator, and for ribbons later 

------------------------------
# dynamic_rotation_connect

built based upon a student request of items for a rigging helper for a mirror and handling axis swapped rotations, for symmetrical rig linking

------------------------------
# edge_loop_to_loc

an aid for a facial rigging generator for lips etc based upon topology as a preview 

----------------------------
# face_center_joint

for surface rivets for belt buckles, armor, badges, and eye rigging via Euclidian distance to place a joint in the center of the selected faces

-------------------------------
# joint_from_locators

turning a previz of locator hierarchy into a skeleton, with a ui to do some customization such as unreal, zero end joints, orientations selected. One of my more helpful scripts, excluding dinoUI, and isolated to share with others

-------------------------------
# joint_loc_orient_prefix

a combined tool...joint name management, locator to joint conversion, zeros residual rotation values and aligns local rotation axis down the chain

-------------------------------
# normal_loc

positioning a locator and adjust its rotation based on normals averages

-------------------------------
# override_color_joints_selected

after creating the hierarchy, I can color the joints themselves with a quick palette, and I figured out how to color buttons

-------------------------------
# prefix_delete_replace

ability to rename with a desired prefix, replace, delete them, of selected objects

-------------------------------
# ribbon_tool_v05

ribbon creation tool for rigging mainly for props and facial

-------------------------------
# rotate_object_preview

a short script to duplicate and move over in a grid patten an object to create a still image for viewing

--------------------------------

# suffix_checker
created for pipeline and passed to others to define desired geo, grp, ctrl, and loc naming all at once especially for a team with two riggers to ensure no human error
